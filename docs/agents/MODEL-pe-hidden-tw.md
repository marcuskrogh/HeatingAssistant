# Model: Hidden wall initial state in 2R2C parameter estimation

## Problem statement

Identify structural 2R2C parameters \(\theta\) from indoor air-temperature
measurements only, with the wall-node initial temperature a decision variable
on each time-separated data window. The plant stays 2R2C. Wall temperature
along a window is not a parameter-estimator decision; it is generated by the
procedure chosen later (open-loop simulation or Kalman-filter iteration).

## Notation

| Symbol | Meaning |
|--------|---------|
| \(T_{\mathrm{a}}\) | Indoor air temperature (state; measured) |
| \(T_{\mathrm{w}}\) | Wall / envelope node temperature (state; unmeasured) |
| \(T_{\mathrm{out}}\) | Outdoor air temperature (exogenous) |
| \(x = (T_{\mathrm{a}}, T_{\mathrm{w}})^{T}\) | 2R2C state |
| \(y^{m} = T_{\mathrm{a}}\) | Measurement |
| \(\theta\) | Structural 2R2C parameters (existing plant; not re-derived here) |
| \(i\) | Index of a time-separated estimation window |
| \(t_{0}^{(i)}\) | Start time of window \(i\) |
| \(T_{\mathrm{w}}(t_{0}^{(i)})\) | Wall initial temperature on window \(i\) (decision variable) |
| \(L_{i}, U_{i}\) | 24-hour indoor/outdoor box edges before \(t_{0}^{(i)}\) |
| \(\Delta t_{\min}\) | Interior-gap threshold (open numerical value) |
| \(J\) | Estimation objective (shell; concrete form follows procedure fork) |

## Formulation

**Plant.** Existing 2R2C dynamics. Measurements observe indoor air only.

**Decision vector.** Shared structural \(\theta\), plus one wall initial
temperature per time-separated window:

\[
\{\theta\} \cup \{ T_{\mathrm{w}}(t_{0}^{(i)}) \}_{i}
\]

**Generated wall trajectory.** On window \(i\), \(T_{\mathrm{w}}(t)\) for
\(t > t_{0}^{(i)}\) is not a PE decision. It is produced by either

1. open-loop simulation of the 2R2C ODE from \(T_{\mathrm{w}}(t_{0}^{(i)})\), or
2. iterating a Kalman filter from that same initial condition.

Which of (1) or (2) is used is a later direction choice. Both take
\(T_{\mathrm{w}}(t_{0}^{(i)})\) as a decision.

**Windows.**

- Time-separated datasets each have their own \(T_{\mathrm{w}}(t_{0}^{(i)})\);
  structural \(\theta\) is shared.
- Overlapping datasets are merged into one window (one \(T_{\mathrm{w}}(t_{0})\),
  one consistent wall trajectory).
- Interior gap in a dataset: if duration \(\ge \Delta t_{\min}\), split and add
  another \(T_{\mathrm{w}}(t_{0})\); if smaller, carry one wall state through
  the hole. Fallback if carrying through small holes is ineffective: treat any
  hole as two datasets.

**Bounds.** For each window \(i\), over the 24 hours before \(t_{0}^{(i)}\):

\[
\begin{aligned}
L_{i} &= \min(T_{\mathrm{a}}, T_{\mathrm{out}}), \\
U_{i} &= \max(T_{\mathrm{a}}, T_{\mathrm{out}}), \\
T_{\mathrm{w}}(t_{0}^{(i)}) &\in
  \bigl[ L_{i} - 0.25(U_{i}-L_{i}),\;
         U_{i} + 0.25(U_{i}-L_{i}) \bigr].
\end{aligned}
\]

The 25% width margin may be tightened later if fits improve. No extra floor
beyond this box.

**Objective (shell).** Score predicted indoor air against \(y^{m}\). Concrete
\(J\) (open-loop simulation MSE vs filter innovations / prediction-error) follows
the open-loop vs Kalman fork and is not chosen here.

## Assumptions

- Same 2R2C family; no extra wall-temperature sensors.
- \(T_{\mathrm{w}}(t_{0})\) is necessary as a decision; the Kalman filter (when
  used) reconstructs \(T_{\mathrm{w}}(t)\), not \(T_{\mathrm{w}}(t_{0})\).
- Overlap is resolved by merging datasets rather than dual wall initials on
  the same time span.
- Indoor/outdoor climate bounds the wall initial; 25% of the 24-hour box width
  is a starting margin, not a physical law.

## Algorithmic choices

- Do **not** treat the full wall trajectory as PE decision variables.
- Do **not** commit a staged split of \(\theta\) by night / solar / heater-off.
  Constructing or scoring windows where solar gain \(\approx 0\) or heater
  power \(\approx 0\) is an admissible direction to evaluate in define, not
  part of this formulation.
- Open-loop vs Kalman generation of \(T_{\mathrm{w}}(t)\) stays a fork.

## Numerical considerations

- \(\Delta t_{\min}\) is unspecified.
- Box degenerates toward a point when \(U_{i} \approx L_{i}\) (indoor and outdoor
  nearly equal for 24 hours); that is accepted.
- Margin 0.25 may be reduced later; not increased in this spec.

## Open items

- Open-loop simulation vs Kalman-filter iteration for \(T_{\mathrm{w}}(t)\)
  (and thus concrete \(J\)).
- Numerical value of \(\Delta t_{\min}\).
- Whether solar-off / heater-off constructed datasets are in the first product
  slice (define).
- Whether the 25% margin is tightened after seeing fits (define / later).
