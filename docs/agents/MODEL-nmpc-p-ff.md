# Model: Hierarchical mean OCP + P tracking

## Problem statement

Replace the linearised QP in the happy path with a **two-rate** controller on the
existing house 2R2C plant:

- **Slow:** a nonlinear OCP on the *mean* ODE produces a nominal path
  \((T_{\mathrm{ref}}, u_{\mathrm{ref}})\).
- **Fast:** a P-law with feedforward \(u_{\mathrm{ref}}\) tracks
  \(T_{\mathrm{ref}}\) using the EKF air estimate.

Failed slow solves keep the last path. Five hours of consecutive failures
(including timeouts) command every heater to \(u = 0\) and raise a persistent
notification. The linearised QP is not in the happy path.

This is finding docs for `/sandbox SWD-394` and `/define SWD-395`. It is not
product UX.

## Notation

| Symbol | Meaning |
|--------|---------|
| \(x\) | Full control state: air \(T_{\mathrm{a}}\), wall \(T_{\mathrm{w}}\), emitter \(\varphi\) if present |
| \(u\) | Heater command as a fraction; heating-only in \([0,1]\), heat/cool in \([u_{\min},u_{\max}]\) typically \([-1,1]\) |
| \(d\) | Disturbances (outdoor temperature, solar, wind, internal gain, …) |
| \(p\) | Identified / configured parameters (masses, resistances, heater maps, …) |
| \(f\) | Mean drift of `HouseThermalSDE` (same \(f\) as the nonlinear forecast) |
| \(\sigma\) | Process-noise diffusion; **EKF only**, not in the OCP |
| \(F\) | Discrete mean map; first cut **implicit Euler** of \(f\) over the slow step (ESDIRK later if needed) |
| \(T_{s}\) | Fast period (EKF then P). Default \(15\,\mathrm{min}\), configurable |
| \(T_{\mathrm{NMPC}}\) | Slow OCP period. Study default \(1\,\mathrm{h}\); sandbox may change it |
| \(T_{H}\) | Look-ahead. Default \(36\,\mathrm{h}\) (typical price-forecast length), configurable |
| \(N\) | Slow steps: \(N = T_{H} / T_{\mathrm{NMPC}}\) |
| \(M\) | Integer \(T_{\mathrm{NMPC}} / T_{s}\) (default \(4\) if \(1\,\mathrm{h}\) / \(15\,\mathrm{min}\)) |
| \(U^{\ast} = (u^{\ast}_{0},\ldots,u^{\ast}_{N-1})\) | Optimal slow input sequence (single shooting) |
| \(u_{\mathrm{ref}}(\tau)\) | Zero-order hold of \(u^{\ast}_{n}\) on \([t_{n}, t_{n+1})\) |
| \(T_{\mathrm{ref}}(\tau)\) | Air temperature from propagating \(F\) on that interval under \(u^{\ast}_{n}\) |
| \(\hat{T}_{\mathrm{a}}\) | EKF air estimate after predict (actual \(u\)) + measurement update |
| \(K_{p}\) | P gain on the **heater** config; one scalar for heat and cool; units: fraction / K |
| \(\pi_{n}\) | Electricity price on slow step \(n\) |
| \(J\) | Slow cost: same purpose as today’s QP |

Time grids:

\[
t_{n} = n\, T_{\mathrm{NMPC}},\quad
\tau_{k} = k\, T_{s},\quad
n \in \{0,\ldots,N\},\quad
k = 0,1,2,\ldots
\]

## Formulation

### Mean plant (OCP and T_ref rollout)

\[
\frac{\mathrm{d}x}{\mathrm{d}t} = f(x,u,d,p)
\]

Stochasticity is **not** in this equation. The CD-EKF keeps \(\sigma\) and the
sensor noise. The OCP is the expectation / certainty-equivalent problem on \(f\).

Heater power \(\phi(u)\) (piecewise-linear heat/cool, COP, scales) stays inside
\(f\). The P-law commands \(u\) only.

### Slow OCP (single shooting)

Decisions: \(U\) only. States are generated by rolling \(F\):

\[
\begin{aligned}
x_{0} &= \hat{x}(t_{n_{0}}), \\
x_{n+1} &= F(x_{n}, u_{n}, d_{n}, p), \\
u_{\min} &\le u_{n} \le u_{\max}.
\end{aligned}
\]

\(\hat{x}(t_{n_{0}})\) is the full EKF state at the slow instant (air, wall,
emitter). One OCP for the **house** (inter-room \(R_{ij}\) included), matching
today’s QP.

Cost \(J(U)\) is **essentially identical** to the current linearised MPC:

- comfort **zone** control with **soft** band constraints (no extra setpoint
  pull);
- input **rate-of-move** (ROM) penalty on \(\Delta u_{n} = u_{n} - u_{n-1}\)
  on the slow grid, with \(u_{-1}\) the last **applied** P command;
- **energy-price** term on electrical draw (spot \(\pi_{n}\) × electrical
  energy over \(T_{\mathrm{NMPC}}\)).

If the price forecast is shorter than \(T_{H}\), persist the last price (same
padding as today).

NLP: **SciPy** (SLSQP or trust-constr — sandbox choice) in the **App** process.
A wall-clock **timeout is non-convergence**. IPOPT / CasADi is parked (shipping
cost). Warm-start from the last \(U^{\ast}\) when it exists.

On success: store \(U^{\ast}\) and the mean air path \(T_{\mathrm{ref}}(\tau)\)
obtained by propagating \(F\) under zero-order-hold \(u^{\ast}_{n}\) on each
slow interval (fine step \(T_{s}\)).

On failure: keep the last successful path. After **five hours** of consecutive
failures (timeouts included): \(u = 0\) on every heater and a persistent
notification.

### Fast loop (every \(T_{s}\))

Order at \(\tau_{k}\):

1. **EKF** predict with the **actual** previous P command (not \(u_{\mathrm{ref}}\)),
   then measurement update from the room sensor. Output \(\hat{T}_{\mathrm{a},k}\).
2. **P-law** (one heater per room in this cut):

\[
u_{k} = \mathrm{clip}\bigl(
  u_{\mathrm{ref},k} + K_{p}\bigl(T_{\mathrm{ref},k} - \hat{T}_{\mathrm{a},k}\bigr),
  u_{\min}, u_{\max}
\bigr)
\]

\(K_{p} > 0\) is configured on the heater. The same gain is used for heating and
cooling; heat vs cool **power** scaling is in \(f\). Heating-only:
\([u_{\min},u_{\max}]=[0,1]\). Heat/cool: typically \([-1,1]\).

Positive error (too cold) increases heating; negative error cuts heat and, if
allowed, cools.

## Assumptions

- No open-loop instability that would forbid single shooting on this plant.
- Nominal solar, outdoor, and price are already in the OCP path; P rejects
  residual mismatch only.
- First cut: one heater per room. Split-range is out of scope.
- Collocation is parked; implicit Euler first; ESDIRK if Euler is too slow.
- NMPC and EKF/P do not run on the Home Assistant Core event loop (`SWD-254`).

## Algorithmic choices

| Choice | Decision |
|--------|----------|
| Slow problem | Mean ODE OCP (expectation); \(\sigma\) only in EKF |
| Transcription | Single shooting in \(U\) |
| Discrete map \(F\) | Implicit Euler of \(f\); ESDIRK later if needed |
| NLP | SciPy in App; timeout = fail |
| Fast law | P + \(u_{\mathrm{ref}}\) bias; no I, no D, no linearised QP |
| \(T_{\mathrm{ref}}\) | Mean rollout under \(U^{\ast}\) on each slow interval |
| \(u_{\mathrm{ref}}\) | \(u^{\ast}_{n}\) held on that interval |
| EKF input | Actual P command |
| P “measurement” | \(\hat{T}_{\mathrm{a}}\) (not raw \(y\)) |
| \(K_{p}\) | Heater config; one gain both directions |
| Look-ahead | Default \(T_{H}=36\,\mathrm{h}\), configurable |
| Fast period | Default \(T_{s}=15\,\mathrm{min}\), configurable |
| Fail | Last path; 5 h consecutive → \(u=0\) + notify |

## Numerical considerations

- Slow period \(T_{\mathrm{NMPC}}\) (study start \(1\,\mathrm{h}\)) is a
  **sandbox** decision: score solve-time reliability and closed-loop
  comfort/cost at \(15\,\mathrm{min}\), \(1\,\mathrm{h}\), \(2\,\mathrm{h}\).
- \(N = T_{H}/T_{\mathrm{NMPC}}\) must stay an integer (enforce in config).
- SciPy method (SLSQP vs trust-constr), iteration cap, and timeout seconds are
  sandbox / define.
- Numeric default for \(K_{p}\) is not chosen here (configurable; sandbox may
  propose a starting value).
- Implicit Euler sub-steps inside each slow interval should match the existing
  nonlinear-forecast integrator unless ESDIRK replaces \(F\).
